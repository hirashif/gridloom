FIELD GUIDE
Two minutes, then you're dangerous.
1.Add a key (Settings → Key vault). fal.ai gets you five models on one key. Keys live in this browser only — we have no server to send them to.
2.Generate is for one careful image; Compare runs one prompt across every model and seed at once. The grid is where you find the winner — mark it with your pen.
3.Keep what works. Everything auto-saves to the Library with full settings. A setup worth repeating? Save it as a Recipe and re-run it in one click.
Costs. You pay providers directly: $0.003–$0.04/image. Every run shows its price before you press the button.
Knobs vary by model. FLUX dev exposes steps + guidance; others manage them internally. Hidden ≠ missing.
Seeds = repeatability. Same prompt + model + seed ≈ same image. Fix a seed to iterate on wording; sweep seeds to explore.
Back up. Your library lives in this browser. Settings → Export everything gives you a portable zip.
